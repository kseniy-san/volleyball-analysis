# Сущности базы данных:

---
## 1. User (Пользователь)
Хранит данные о пользователях системы.
- id (целое число, первичный ключ)
- email (строка, уникальная)
- password_hash (строка)
- created_at (дата и время)

## 2. Video (Видео)
Хранит информацию о загруженных видеофайлах.
- id (целое число, первичный ключ)
- user_id (целое число, внешний ключ к User.id)
- filename (строка)
- duration (дробное число, длительность в секундах)
- fps (дробное число, кадры в секунду)
- width (целое число, ширина)
- height (целое число, высота)
- status (enum: uploaded, queued, processing, completed, error)
- created_at (дата и время)

## 3. ProcessingJob (Задача обработки)
Хранит информацию о процессе обработки видео нейросетью.
- id (целое число, первичный ключ)
- video_id (целое число, внешний ключ к Video.id)
- status (строка)
- progress (целое число: от 0 до 100)
- started_at (дата и время)
- finished_at (дата и время)

## 4. Rally (Розыгрыш)
Хранит найденные игровые моменты.
- id (целое число, первичный ключ)
- video_id (целое число, внешний ключ к Video.id)
- number (целое число, порядковый номер)
- start_time (дробное число, время начала в секундах)
- end_time (дробное число, время окончания в секундах)
- start_frame (целое число, начальный кадр)
- end_frame (целое число, конечный кадр)
- serve_side (enum: unknown, near, far)

## 5. Detection (Детекция)
Хранит координаты мяча и игроков.
- id (целое число, первичный ключ)
- video_id (целое число, внешний ключ к Video.id)
- frame (целое число, номер кадра)
- class (строка, что нашли: ball, player)
- x, y, w, h (дробные число, координаты)
- confidence (дробное число, уверенность)

---
## Связи (Relationships)
- Один User может иметь много Video (связь 1 ко многим).
- Одно Video имеет много ProcessingJob (связь 1 ко многим).
- Одно Video имеет много Rally (связь 1 ко многим).
- Одно Video имеет много Detection (связь 1 ко многим).
