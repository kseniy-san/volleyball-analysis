## Исследование параметров сегментации розыгрышей (ИР 4)

В ходе работы над анализом видео были использованы YOLO26 и скрипт для извлечения координат мяча. 
В результате был получен временной ряд с координатами мяча для каждого кадра (ball_tracks.json). 

Для выделения розыгрышей были определены два ключевых параметра:
1. **MIN_RALLY_DURATION** (Минимальная продолжительность розыгрыша).
2. **MAX_GAP** (Максимальный пропуск детекции мяча).

### Проведенные эксперименты:
*   Эксперимент 1 (MAX_GAP = 3.0, MIN_RALLY_DURATION = 2.0): 
Алгоритм нашел 3 розыгрыша. Однако при визуальной проверке было выявлено,
что второй отрезок (3.7 сек) является не игрой, а возвратом мяча под сетку.
*   Эксперимент 2 (MAX_GAP = 4.5, MIN_RALLY_DURATION = 2.0):
Алгоритм объединил все отрезки в один (51 сек), 
так как паузы между реальными розыгрышами были меньше 4.5 секунд.
*   Эксперимент 3 (MAX_GAP = 3.0, MIN_RALLY_DURATION = 4.0): 
Ложный короткий отрезок был успешно отфильтрован. Алгоритм выделил ровно 2 реальных розыгрыша.

### Итоговые параметры:
*   MIN_RALLY_DURATION = 4.0 — позволяет отсечь случайные короткие касания мяча.
*   MAX_GAP = 3.0 — корректно разделяет разные розыгрыши, так как реальные паузы между ними превышают 3 секунды.

### Результат:
Найденные интервалы были успешно сохранены в базу данных SQLite через SQLAlchemy:
*   Розыгрыш 1: с 6.87 сек по 18.89 сек.
*   Розыгрыш 2: с 28.9 сек по 45.08 сек.
